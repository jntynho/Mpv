# MPV 0.7 — Iconsax Outline / Broken

يمكن التبديل من Settings → Appearance → Icon style بين **Outline** (الافتراضي) و**Broken**. الاختيار محفوظ في تفضيلات التطبيق، ويطبَّق على الواجهة والمشغل واللوحات والإشعارات وPiP دون إعادة إنشاء Activity أو سطح الفيديو.

## المجلد الثابت

لم يتغير `library_folder.xml`، ولا لون المجلد أو موضعه أو حجمه 88×76dp في الرئيسية. إنه رسم ثابت خارج كتالوج التبديل. بصمته قبل التعديل وبعده:

```
3a38cf0350069410870c3fbe51314d4e4f6c6cb2de1beaecf3f2e0c530f786b4
```

الرسم الحالي أصله Font Awesome؛ الإبقاء عليه كما طلب المستخدم يقتضي الإبقاء على نسبته وترخيصه لهذا الأصل وحده. أُزيلت بقية رسومات Font Awesome وتعريفاتها وموارد المشغل القديمة. النسبة المحفوظة موثقة في `third_party/folder-artwork` وأصول الترخيص داخل التطبيق. شعار التطبيق يستخدم رسم Play من Iconsax Outline بدل الرسم السابق.

## التنفيذ

- يقرأ Theme إعداد `icon_style` ويزوّد CompositionLocal بالنمط الحالي؛ كل أيقونة تقرأ الاختيار عند الرسم. لا كائنات Vector ثابتة تحفظ اختيارًا سابقًا.
- كتالوج واحد يربط الأسماء الدلالية بموارد Android للنمطين. Compose والإشعارات وPiP تستخدم الموارد نفسها؛ لا نسخ من مسارات الرسم داخل حزم filled/outlined/rounded.
- تحولت أيقونات محاذاة الترجمة المخزنة في enum إلى getters تقرأ النمط الحالي، حتى تتغير مع بقية الواجهة.
- مستمع ضمن دورة حياة PlayerActivity يعيد تطبيق معاملات PiP عند تغيير الاختيار. خدمة الخلفية تستمع للاختيار وتحدث الإشعار عند نشاطه، وتلغي المستمع عند إنهائها.
- رموز التقديم والتراجع عامة؛ لا تفرض رقم 10 على إعداد قفزة يمكن للمستخدم تغييره.
- أضيفت موارد RTL للرجوع ومحاذاة النص، بينما تظل رموز زمن الوسائط غير معكوسة.
- احتُفظ بالرموز المطلوبة فقط كموارد Vector. لا اعتماد Flutter، ولا خط أيقونات كامل، ولا تنزيل رسومات أثناء التشغيل.

## المصدر والترخيص

Iconsax بواسطة Lusaxweb، من commit `e5dba15361f69d34d0f3f3f35408a28fe74c5727`. ترخيص Iconsax الأصلي يسمح بالاستخدام الشخصي والتجاري وفق شروطه، وهو **ليس MIT**. الترخيص ومصدر التحويل والبصمات موجودة في `third_party/iconsax` وفي تراخيص التطبيق.

يمكن إعادة التوليد من أرشيف SVG الرسمي ذي البصمة المثبتة:

```sh
python3 scripts/generate-iconsax.py /path/to/Svg.zip
python3 scripts/check-icon-assets.py
```

أُضيف فحص الأصول إلى GitHub Actions قبل البناء. يتحقق من توفر النمطين، وبصمات الموارد، ودعم RTL، وبقاء أصل المجلد وقياسه دون تغيير.

## التحقق والحدود

نجح `testDebugUnitTest lintDebug assembleDebug assemblePreview`: **16 اختبارًا ناجحًا، وصفر أخطاء Lint**، مع بقاء 370 تحذيرًا وhint واحد. اجتازت ملفات ARM64 وARM32 وUniversal فحص التوقيع ومحاذاة 16KB. تأكدنا من وجود موارد Outline وBroken للضوابط الأساسية داخل كل APK، ومن تطابق ملف المجلد المعبأ في APK مع الإصدار السابق بالبايت. طابقت أقسام `.text` و`.dynsym` للمكتبات الأصلية العشرين محرك mpv الموزع دون تغيير.

القياس المحلي مقابل نسخة 0.6 السابقة، بوحدة MB العشرية:

| المعمارية | 0.6 | 0.7 | الزيادة الفعلية |
|---|---:|---:|---:|
| ARM64 | 20.225827 MB | 20.350199 MB | 124.372 KB، نحو 0.615% |
| ARM32 | 19.552853 MB | 19.677214 MB | 124.361 KB، نحو 0.636% |

النسخة الشاملة الجديدة 32.574997 MB. هذه مقارنة الإصدارين بما يشمل إعداد التبديل وموارد الأيقونات، وليست قياسًا معزولًا لـBroken وحده. كتالوج المصدر يتضمن 81 اسمًا دلاليًا يشارك 142 موردًا بين النمطين، إضافة إلى ست نسخ RTL؛ لم تُضمَّن المكتبة الكاملة. لا يوجد هاتف أو محاكي متصل في هذه البيئة، لذلك التبديل المرئي الفعلي داخل المشغل وPiP والإشعارات يحتاج تجربة جهاز. فحص المصدر والبناء لا يعادلان اختبار تشغيل الفيديو على هاتف.

لم يتغير محرك mpv ولا إعدادات تشغيله أو سجل الملفات. المشكلات السابقة التي تحتاج عملاً مستقلاً موثقة في [تدقيق المشغل 0.6](PLAYER-AUDIT-0.6.md).
